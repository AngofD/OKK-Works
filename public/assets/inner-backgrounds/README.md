# OKK Works inner-page backgrounds

These four backgrounds are prepared for the redesigned internal pages. They intentionally contain no text or interface elements.

- `services-orbit-bg.webp` — services page; stronger lower-left sphere and upper-right orbit.
- `work-orbit-bg.webp` — portfolio page; darkest and least visually busy.
- `process-orbit-bg.webp` — process page; abstract path with glowing milestones on the left.
- `contact-orbit-bg.webp` — contact page; large left halo and a quiet right zone for the form.

Use them as decorative backgrounds with `background-size: cover`, a dark color fallback, and an additional subtle dark overlay where content contrast requires it. On narrow screens, adjust `background-position` per page rather than stretching the image.
